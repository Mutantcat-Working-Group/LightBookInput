程序员模式给写代码、查说法的场景：中文照常打，需要英文时点按 `~`（·），候选右侧立即出现对应英文，方向键选择当前候选的释义，按数字或空格直接上屏。
英文只来自本机的一张中英释义表，不联网、不切换输入法、不改任何设置。

## 用法

1. 像平常一样输入拼音，候选窗口出现。
2. 点按 `~`（·）：候选右侧列出英文，拼音行右侧提示当前处于程序员模式。
3. 用 `↑` / `↓` / `←` / `→` 在当前高亮候选的英文释义之间循环切换；只有一条释义时也会保留选择光标。
4. 按 `1` 至 `9` 上屏对应候选当前选中的英文，按空格上屏高亮候选的英文。英文上屏时吃掉整段拼音。
5. 再点按一次 `~`（或按 `Esc`、直接按其他键）即回到普通中文输入。

| 操作 | 按键 |
|---|---|
| 进入程序员模式 | 点按 `~`（·） |
| 换当前高亮候选的英文释义 | `↑` / `↓` / `←` / `→` |
| 上屏第 N 个候选的英文 | `1` 至 `9` |
| 上屏高亮候选的英文 | 空格 |
| 退出 | 再按一次 `~`、`Esc`，或直接按其他键 |

选中某条释义后按数字键时，若那一格候选的释义条数少于当前选中的序号，则回退到它第一条释义。方向键在程序员模式里只切第二行的释义光标，不改第一行的候选高亮。

## 退出方式

- **再按一次 `~`**：三个平台都用得上，是最直接的退出方式。
- **`Esc`**：退出模式，拼音与候选保持原样。
- **按其他键**：字母、翻页键等都先退出模式，再按普通按键处理，不会打出英文。

只有在候选窗口开着时才能进入：没有候选时 `~` 仍是最初的标点键。

## 覆盖范围

随包释义表覆盖整个词库，约 23.2 万词，并补充程序设计与语法、并发、数据库、网络、安全、架构、测试、研发流程和人工智能等开发者术语；词库多字词九成以上有英文。某个候选没有英文时照常上屏中文，不会卡住或报错。

本模式常开，不需要在「偏好设置 → 快捷键」里配置，也没有快捷键可改。

## 与英文模式的区别

英文模式（[英文模式](english-mode.md)）是切到纯英文输入，靠 `Caps Lock` 或单击 `Shift` 进入；
程序员模式是中文输入过程中的临时状态，一句话说到一半要嵌入英文时更顺手，再点按一次 `~` 就回到中文。
