程序员模式给写代码、查说法的场景：中文照常打，需要英文时按住 `~`（·）不松手，候选右侧立即出现对应英文，按数字或空格直接上屏。
英文只来自本机的一张中英释义表，不联网、不切换输入法、不改任何设置。

## 用法

1. 像平常一样输入拼音，候选窗口出现。
2. 按住 `~`（·）：候选右侧列出英文，拼音行右侧提示当前处于程序员模式。
3. 按 `1` 至 `9` 上屏该候选的英文，按空格上屏第一个候选的英文。英文上屏时吃掉整段拼音。
4. 松手即回到普通中文输入。

| 操作 | 按键 |
|---|---|
| 进入程序员模式 | 按住 `~`（·） |
| 上屏第 N 个候选的英文 | `1` 至 `9` |
| 上屏第一个候选的英文 | 空格 |
| 退出 | 松开 `~`、再按一次 `~`、`Esc`，或直接按其他键 |

## 退出方式

- **松开 `~`**：macOS 上收到松键即退出。
- **再按一次 `~`**：两个平台都用得上；Windows 收不到松键，这是最直接的退出方式。
- **`Esc`**：退出模式，拼音与候选保持原样。
- **按其他键**：字母、翻页键等都先退出模式，再按普通按键处理，不会打出英文。

只有在候选窗口开着时才能进入：没有候选时 `~` 仍是最初的标点键。

## 覆盖范围

随包释义表覆盖整个词库，约 23.9 万词，词库多字词九成以上有英文。某个候选没有英文时照常上屏中文，不会卡住或报错。

本模式常开，不需要在「偏好设置 → 快捷键」里配置，也没有快捷键可改。

## 与英文模式的区别

英文模式（[英文模式](english-mode.md)）是切到纯英文输入，靠 `Caps Lock` 或单击 `Shift` 进入；
程序员模式是中文输入过程中的临时状态，一句话说到一半要嵌入英文时更顺手，松手就回到中文。
