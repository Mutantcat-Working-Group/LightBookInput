轻书是一个拼音输入法，另外带一个程序员模式：点按 `~`（·）时，候选旁立即列出英文，按数字或空格直接上屏。
它首先是一个完整的输入法：整句输入、简拼、拼写纠错、模糊音、双拼、英文模式，全部在本机完成，不上传数据。

macOS 版与 Windows 版均为测试版，两个平台功能相同，按键按各自系统的习惯设计，见 [按键与快捷键](getting-started/keys.md)。Linux 版刚起步，使用 Fcitx5 默认候选面板，见 [Linux](getting-started/linux.md)。

## 从哪里开始

- 尚未安装：[安装](getting-started/install.md)。
- 已安装：[第一次输入](getting-started/first-input.md)，介绍中英切换、选词、翻页与选错后的退回。
- 查某个键的作用：[按键与快捷键](getting-started/keys.md)，两个平台并列。
- 一边打字一边要英文：[程序员模式](input/programmer-mode.md)。
- 联网补全整句、答字：[云联想](cloud/index.md)，缺省关闭，需自行填写 AI 服务商。
- 轻书在本机保存了哪些文件：[数据与日志](help/data-and-logs.md)。

## 三条原则

- **输入优先。** 任何为输入之外的功能增加的延迟、弹窗与干扰都视为设计错误。
- **中文是主线。** 程序员模式的英文只是候选旁边的辅助信息，只在点按 `~` 后出现，不打断中文输入。
- **全部在本机。** 拼音转换、词库、学习、中英释义表均不联网；云联想是可选的补充，数据发送给用户自行填写的服务商，不经过轻书。
